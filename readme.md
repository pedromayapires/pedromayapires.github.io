# Project Name - A Brief Description

A React-based web application with features for user interaction, settings management, and year/month navigation. Built using React hooks and context API for global state management.

## Features

- Copy text to clipboard functionality
- Settings UI with on-hover help icons
- Year/month navigation system
- Dynamic page breaking for print
